Place operator-owned PNG, JPEG, GIF, WebP or AVIF banners here (up to 10 MiB, 8000x4000).
No SVG, symlinks or subdirectories. At most 256 validated images, sorted by filename.
The server hashes the UTC minute, rehashing if the previous image would repeat.
Only the image is shown; there is no visible countdown. One image necessarily repeats.
If this catalog is empty the existing /static/banner.png is used.
This branch did not contain the banner files mentioned from another branch; copy/merge them separately.
