# Post reactions

Put trusted operator-provided PNG, GIF, JPEG or WebP files here. Up to 128 images,
2 MiB each, maximum 512×512. Use ASCII filenames, e.g. `like.png`, `laugh.gif`:
`[A-Za-z0-9][A-Za-z0-9_-]{0,63}.EXT`. No SVG, symlinks or visitor uploads.
Optional `reactions.json`: `{"like":"Like","laugh":"Laugh"}` (keys omit extension).
Labels are operator content, not automatically translated. Three original basic
icons are bundled: like, heart, laugh. Replace or remove them freely.
Images appear automatically; no database registration or code edit is needed.
Removal hides that reaction and its counter without deleting historical votes.
Each signed-in user has one reaction per post and can change/remove it.
